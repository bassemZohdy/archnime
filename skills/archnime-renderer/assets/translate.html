Transition Diagram Translator

Paste a transition-diagram/1.0 YAML document, validate its structure and generated geometry, then download a ready-to-open HTML diagram. Download stays disabled until structural and blocking geometry checks pass; route fallbacks remain visible as advisory notices.

Waiting for YAML.

When this page is served from the repository, the adjacent template.html is loaded automatically. The picker is a fallback for local file use.

Validation pipeline
  1. Parse YAML with the pinned js-yaml build.
  2. Run the browser port of the DSL schema and lint rules.
  3. Map YAML to the portable renderer MODEL.
  4. Run DiagramEngine.selfCheck() across every stage.
  5. Compute the layout of every state a click can reach and store it in the page.
  6. Inline the local renderer sidecars when available and enable download.
