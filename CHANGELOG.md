## [Unreleased]

### Added

- **TASK-032** (docs): Record the build-time layout decision and its evidence in `docs/build-time-layout.md` (current renderer to be archived by tag and branch, old runtime not kept, removal gated on a parity check; no renderer change yet), link it from the README, and add the follow-up tasks to `TODO.md` under a `build-time-layout` lane. Validated: `npm run check-skills`. Docs: added docs/build-time-layout.md, updated README.md, TODO.md.
- **TASK-034** (test): Add `headless_layout_check.mjs`, which runs `DiagramEngine.layoutStage` in plain Node with no page on five fixtures (flat, nested packages, flow, ELK, force), writes the geometry as JSON and fails when it differs from what the engine computes in the built page; wired into `npm run test:browser`. Result recorded in `docs/build-time-layout.md`: identical geometry on all five, 0.2 to 16 s, 13 to 26 KB. No renderer change. Validated: `node skills/archnime-renderer/tests/headless_layout_check.mjs`, `npm test`. Docs: updated docs/build-time-layout.md, skills/archnime-renderer/tests/README.md.
- **TASK-036** (test): Add two hand-authored fixtures, `free-form-mesh.json` (a peer mesh with call cycles, not lane-aligned) and `nested-three-levels.json` (packages nested three deep), to the render check and the headless layout comparison, which now also reports the in-page layout time. Both render with a clean self-check and identical headless and in-page geometry. Validated: `npm run check-fixtures`, `node skills/archnime-renderer/tests/render_check.mjs`, `node skills/archnime-renderer/tests/headless_layout_check.mjs`, `npm test`. Docs: updated docs/build-time-layout.md, skills/archnime-renderer/tests/README.md.
- **TASK-033** (docs): Archive the renderer that computes layout in the page as the tag `legacy-runtime-layout` and the fixes-only branch `legacy/2.x`, both at release 2.1.1, and say so in the README. Validated: `git tag -l legacy-runtime-layout`, `git ls-remote --heads origin legacy/2.x`. Docs: updated README.md.
- **TASK-037** (test): Add `playback_gate_check.mjs`, the comparison harness measurements as a regression gate on a staged diagram and a flow at 1280 px: Pause freezes motion, Next, Back and jump work while playing, no text under 12 px, run length; wired into `npm run test:browser`. Targets the renderer does not meet yet (text down to 5.5 px, flow dashes still animating after Pause) are recorded in `playback-gate-budgets.json` and held at their current values. No renderer change. Validated: `node skills/archnime-renderer/tests/playback_gate_check.mjs`, `npm test`. Docs: updated docs/build-time-layout.md, skills/archnime-renderer/tests/README.md.

## [2.1.0] - 2026-11-22
